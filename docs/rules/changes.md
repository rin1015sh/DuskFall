# 룰북 변경 기록

룰북에 없던 규칙이나 바뀐 규칙을 적는다. 룰북 문서에 옮기면 '반영'에 표시한다.

| 날짜 | 내용 | 이유 | 관련 단계 | 반영 |
| --- | --- | --- | --- | --- |
| 2026-11-22 | '숨음'은 별도 상태를 두지 않고 원문 Hide대로 투명(invisible) 상태로 나타낸다(source = "hide"). 공격 굴림을 하면 풀린다. 숨기로 얻은 투명이 젖음에 풀리는지는 5단계에서 다시 정한다 | 룰북에 '숨음' 상태 정의가 없고, SRD 5.2.1 Hide는 성공 시 Invisible 상태를 준다. 사용자 확인 | 4·5·8 | |
| 2026-11-22 | 주문 전용 상태 '윤곽'(outlined) 추가: 받는 공격 유리(공격자가 볼 수 있을 때), 투명 효과 억제 | Faerie Fire 데이터가 apply_condition outlined를 쓰고, 주문 변환표가 '윤곽: 투명·은신 무효, 공격 유리'로 정해 둠. 4단계 상태 목록에는 없어서 기록 | 4·6 | |
