# 6단계 주문 변환표

> `tools/spells_table.gd`가 `data/content/spells.json`에서 만든다(손으로 고치지 않는다). 수치는 BG3 우선(2026-11-24 — bg3.wiki 대조), BG3에 없는 주문은 SRD 5.2.1 원문을 6단계 공통 변환 규칙으로 바꾼 값이다.

읽는 법: 사용은 클래스 주문 목록(바드·클 = 클레릭·드 = 드루이드·팔 = 팔라딘·레 = 레인저·소 = 소서러·워 = 워락·위 = 위저드), 괄호는 종족·혈통. 1칸 = 1.5m, 10턴 = 1분, '긴 휴식까지' = 원문 1시간 이상, '탐험 전용' = 시전 시간 1분 이상. 출처의 '자체'는 SRD 밖 BG3 주문을 자체 이름으로 만든 것. '공통 규칙대로'는 변환 규칙 밖의 별도 처리가 없다는 뜻이다.
