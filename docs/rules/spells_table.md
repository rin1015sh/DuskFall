# 6단계 주문 변환표

클레릭·위저드 주문 목록과 종족 주문 중 3레벨 이하 150개(+ 4·5레벨 72개·6~8레벨 68개·9레벨 16개 — 2026-11-23 레벨 상한 20)를 6단계 공통 변환 규칙으로 바꿨다. 원문은 SRD 5.2.1 주문 장이고, 이름은 원문 영어를 그대로 두었다(한국어 이름은 현지화 때).

읽는 법: 사용의 클 = 클레릭, 위 = 위저드, 괄호는 종족 혈통이다. 1칸 = 5피트, 10턴 = 1분, '긴 휴식까지' = 원문 1시간 이상, '탐험 전용' = 시전 시간 1분 이상이다. '공통 규칙대로'는 변환 규칙 밖의 별도 처리가 없다는 뜻이다.
