# 컷아웃 캐릭터 그림 규격

룰북 1단계 '스프라이트 방향'의 2D 일러스트 컷아웃 캐릭터에 넣을 부위 그림의 규격이다.
그림이 없는 부위는 코드로 그린 임시 그림(`scenes/battle/cutout_rig.gd`의 `Part`)이 대신 그린다.
같은 이름의 PNG를 넣으면 다시 빌드하지 않아도 다음 실행부터 그 그림을 쓴다.

## 파일 위치와 이름

```text
assets/cutout/<체형>/<부위>.png
```

| 체형 | id | 쓰는 종족 |
| --- | --- | --- |
| 보통 | `medium` | 인간·엘프·드로우·하프엘프·하프오크·티플링·아스트란·드래곤본(임시) |
| 작은 | `small` | 하플링·노움 |
| 드워프 | `dwarf` | 드워프(작은 체형을 넓힌 변형) |

체형·뼈 위치는 `data/rules/body_templates.json`, 종족별 피부·머리 색과 부가 부위는 `data/rules/cutout_looks.json`에 있다.

## 캔버스와 기준점

- 캔버스: 160 × 240 px. 원점(발 사이 바닥)은 가로 가운데, 아래에서 12 px 위.
- 보통 체형 키는 발에서 머리 꼭대기까지 약 176 px. 화면에서는 0.56배로 줄어든다(걷기 시트 캐릭터 키에 맞춤).
- 부위 그림의 기준점은 **뼈 시작점 = 그림 위쪽 가운데**다. 팔다리는 아래로 자라게, 몸통·목·머리는 위로 자라게 그린다.
  - 팔다리(`upper_arm_*`, `lower_arm_*`, `thigh_*`, `shin_*`): 위쪽 가운데가 관절. 길이는 그 뼈의 `len`(보통 체형: 위팔 22, 아래팔 20, 허벅지 44, 정강이 42).
  - 몸통(`torso`): 허리(엉덩이 뼈)가 기준. 위로 46 px까지 어깨.
  - 머리(`head`): 목 끝이 기준. 위로 26 px 정도.

## 방향

앞쪽 대각선(오른쪽 아래를 봄)과 뒤쪽 대각선(오른쪽 위를 봄) 두 방향만 그린다. 왼쪽은 좌우 반전으로 만든다.
뒤쪽 대각선 그림은 `<부위>_back.png`로 둔다(없으면 앞쪽 그림을 쓴다 — 다음 단계).

## 부위 목록(그리기 순서 = `draw_order`)

| 부위 | 뼈 | 메모 |
| --- | --- | --- |
| `torso` | torso | 옷·갑옷 몸통. 갑옷별 그림은 다음 단계에서 `torso_<모양>.png`(chain·plate 등) |
| `neck`, `head` | neck, head | 얼굴은 앞쪽 대각선(3/4) |
| `hair`, `beard`, `ears`, `horns` | head | 종족·개인 차이 |
| `upper_arm_far/near`, `lower_arm_far/near`, `hand_far/near` | 팔 | far = 화면 안쪽 팔(몸 뒤), near = 바깥 팔 |
| `thigh_*`, `shin_*`, `foot_*` | 다리 | |
| `cloak`, `helmet` | torso, head | 장비 칸이 차 있을 때만 |
| `weapon`, `offhand` | hand_near, hand_far | 손잡이가 기준점. 칼날은 위로 |
| `tail` | hips | 티플링 |

## 도트 그림 모드

도트 화면에서는 같은 뼈대를 도트 배율로 줄여 도트 해상도 캔버스에 그린다(`cutout_rig.gd`의 `dot`).
맵 캐릭터는 그림 1px × 0.28(보통 크기) = 화면 1도트, 초상은 × 0.5. 코드로 그린 임시 그림은 부위마다 3단 음영(북서쪽 빛 —
왼쪽 위 1도트 밝은 테, 본색, 오른쪽 아래 1도트 그늘 테)과 1도트 테두리로 그린다. 부위 PNG를 넣을 때도 같은 규칙(밝은 테·그늘 테·
어두운 1도트 테두리, 단계 끊은 색)으로 그리면 지형·소품 도트 그림과 어울린다. 크기는 지금 규격(160 × 240 캔버스) 그대로 그리고,
게임이 도트 배율로 줄인다(가장 가까운 점).

## 색 바꾸기

- 몸통·팔다리 그림은 회색조로 그리면 재질 색(`cutout_looks.json`의 `mat_*`)이 곱해진다.
- 피부·머리 색도 종족 데이터의 색을 곱한다. 얼굴 선·외곽선은 검정으로 두면 색이 바뀌지 않는다.
- 등급(희귀·매우 희귀·전설)은 테두리 빛으로 따로 그린다(그림에 넣지 않는다).

## 애니메이션

뼈 회전 키(도)로 움직인다: 서 있기·걷기·근접 공격·원거리 공격·시전·피격(`body_templates.json`의 `animations`).
쓰러짐은 몸 전체를 눕힌다. 그림은 한 장씩만 그리면 되고, 모든 장비가 같은 동작을 쓴다.
