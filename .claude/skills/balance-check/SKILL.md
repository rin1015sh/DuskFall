# 밸런스 점검

대상: $ARGUMENTS (조우 ID, 몬스터 ID, 클래스·레벨)

1. 기준 파티: 룰북 9단계 예시 전투의 파티(전사·로그·클레릭·위저드, 해당 레벨, 포인트 구매 + 자유 배분 능력치).
2. 조우 난이도는 `docs/srd/09_GameplayToolbox.md`의 조우 경험치 예산으로 계산해 함께 적는다.
3. `tools/sim_battle.gd`로 같은 조우를 시드만 바꿔 200회 돌린다(도구가 없으면 먼저 만든다). 파티와 적 모두 단순 AI(가까운 적 공격, 고지·표면 활용, HP 낮으면 회복).
4. 보고: 승률, 평균 라운드, 쓰러진 횟수, 사망률, 쓴 주문 슬롯·물약, 가장 큰 피해를 낸 행동 3개.
5. 목표에서 벗어나면(예: 보통 난이도인데 사망률 10% 초과) 원인 후보와 조정안(수치·배치·AI)을 제안한다. 규칙 자체를 바꿔야 하면 사용자에게 묻는다.
