# 규칙 점검

대상: $ARGUMENTS (비어 있으면 최근에 바뀐 규칙 코드와 데이터)

1. 대상이 다루는 규칙을 룰북에서 찾는다(단계·표·행).
2. 룰북이 원문을 따르는 항목([원문 유지])은 `docs/srd/`에서 원문 문장도 찾는다.
3. 코드·데이터와 하나씩 비교한다. 특히 자주 틀리는 곳:
   - 가벼운 무기 보조 공격 피해에 능력 수정치를 더하지 않음(재주 예외).
   - 치명타는 주사위만 2배. 피해 수정 순서는 보너스·패널티 → 저항 → 취약.
   - 원거리 근접 불리는 적이 나를 볼 수 있고 무력화되지 않았을 때만.
   - 일반 내성에는 자연 20·1 자동 판정 없음(대화 중 내성·집중 내성은 있음).
   - 밀치기는 밀기만(넘어뜨리기 없음), 무게 한계 = 근력 × 12kg.
   - 단일 대상 효과는 칸 반응 없음.
4. 어긋난 점을 표로 보고한다: 위치(파일:줄), 현재 동작, 룰북/원문(단계·행 또는 파일:줄), 제안. 사용자 확인 전에는 고치지 않는다.
