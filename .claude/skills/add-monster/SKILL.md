# 몬스터 추가

요청: $ARGUMENTS

## 먼저 읽을 것

- 룰북 2단계(재충전 → 고정 쿨다운), 4단계(상태이상, 큰 생물 2×2, 무게), 5단계(시야 원뿔, 숨기 조건), 7단계(0 HP = 즉사), 9단계(악용 사례: 밀림 면역, 적 숨기 제한).
- 원문: `docs/srd/12_MonstersA-Z.md`, `13_Animals.md`.

## 변환 규칙

- 크기 → 점유 칸(작음·보통 1칸, 큼 2×2). 속도·사거리는 칸.
- 감각: 암시야 칸, 시야 원뿔 길이(기본 8칸), 수동 지각.
- `weight_kg`(밀치기·던지기 한계용). 보스는 `push_immune: true`.
- 재충전 5~6 → 3턴 쿨다운, 6 → 6턴.
- 붙잡기 공격 → 속박, 탈진 → 중독 10턴, 귀먹음 → 효과 없음.
- 숨기는 적이 볼 수 없는 위치에서만(9단계).
- 행동은 효과 모델로. 다중 공격은 `multiattack` 목록.
- AI 힌트: 선호 거리, 고지 사용, 표면 회피, 도망 HP 비율.
- 자체 몬스터는 비슷한 CR의 SRD 몬스터를 기준으로 수치를 잡고 근거를 적는다.
- 경험치(BG3, 룰북 7단계): `cr`·`xp`는 SRD 참고값(밸런스용)으로 두고, 처치 경험치는 `level`(1~12)·`xp_category`로 정한다.
  `level` 기본값은 `progression.json` `cr_to_level` 표(CR 1/4 이하 1, 1/2 → 2, 1 → 3, 2 → 4 …). 종류는 보통 `combatant`,
  떼 짐승·졸개 `pack`, 우두머리 `elite`, 중간 보스 `miniboss`, 최종 보스 `boss`, 민간인 `civilian`, 소환수·동료 `zero`.

## 순서

1. 변환안을 보여 주고 확인받는다.
2. `data/monsters/<id>.json` 작성, 필요한 스크립트·테스트 추가.
3. `/balance-check`로 기준 파티와 싸워 보고 결과를 함께 보고한다.
4. `/verify`.
