# 환경 요소 추가

요청: $ARGUMENTS

## 먼저 읽을 것

- 룰북 4단계 전체(태그 목록, 반응표, 표면 규칙, 상태이상, 중첩 규칙)와 9단계 충돌 처리(C·D: 번짐 예고, 물체 파괴 깊이).

## 규칙

- 칸마다 표면 1개, 구름 1개. 새 표면은 반응표를 먼저 보고, 반응이 없으면 덮어쓴다.
- 효과 시점: 칸에 들어갈 때와 그 칸에서 턴을 시작할 때, 같은 턴 같은 효과 1회.
- 내성 DC: 주문이 만든 표면은 시전자 주문 DC, 그 밖은 12.
- 번지는 것은 화염뿐(라운드 끝 직교 1칸). 새 번짐 규칙이 필요하면 사용자에게 묻는다.
- 연쇄 상한(깊이 3, 64칸)을 넘지 않는지 반응 조합을 점검한다.
- 화면에서 읽혀야 한다(원칙 4): 표면 그림, 미리보기 표시, 아군 칸 경고.

## 순서

1. 새 요소와 기존 요소 사이의 반응을 원인(화염·냉기·번개·물) × 대상 표로 정리해 보여 주고 확인받는다.
2. `surfaces.json` / `reactions.json` / `materials.json`에 추가.
3. 테스트: 반응 결과, 지속, 번짐, 연쇄 상한.
4. 필요한 그림·이펙트 목록을 남기고 `/verify`.
